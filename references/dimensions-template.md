# 图表模块基准清单模板（A～L 必测 + M/N 可选扩展 + O 优先级）

> 用法：对比任意表格 SDK 的图表能力时，逐行填充"参评方结论 + 证据强度 + 可修改性通道 + API 名 + 证据 URL"。范围约定：主战场为原生 Excel 图表；M/N 组（数据图表/迷你图）默认不测，用户点名时启用。
> 结论判定顺序：UI 面板 → Facade/API 层 → 内部模型层；"API 层无键"判 ⚠ 不判 ❌，模型层确认无字段才判 ❌（可修改性通道见 verdict-framework.md）。
> 完整表格版见实战产出《图表配置项基准清单.md》（含每行 Excel 基线）。

## M. 数据图表 Data Charts（可选扩展，SJS 独有体系，25 项）
绑定多表数据 / 玫瑰图 / 径向堆叠条形 / 极坐标条形 / K线 / OHLC / 栅格编码分面 small multiples / 明细与颜色编码 / 日期坐标轴 / 正负值配色 / 层次类别轴。
Univer 侧仅需文档查证"有无等价物"，无需深测——此组本身即 SJS 差异化卖点。

## N. 迷你图 Sparkline（可选扩展，37 项）
Excel 兼容 3 种（折线/柱形/盈亏）/ 函数迷你图家族 20+ 种（Excel 无）/ 条形码 12 种（Excel 无）/ xlsx 导入还原 / 自定义 SparklineEx 机制。Univer Pro 疑仅支持 Excel 兼容 3 种，待查证。

## O. 测试计划模式（从官方功能清单反推后，产出《测试计划》文档时遵循）

**来源双轨**：官方功能清单条目（标行号/版本标记）+ Excel 对象模型基准条目（对方未宣传但 Excel 支持的），合并去重，逐项标来源。

**每项四标注**：

## 可修改性通道标注（每个结论并列标注）
- ①文档化 API / ②未文档化 API（实测可用）/ ③内置 UI 面板 / ④仅模型层（无读写入口）
- 判定顺序 UI → API → 模型；通道①～③任一存在即"可修改"，仅④才算"改不了"

## 实战已测结论速查（SpreadJS v19.2.2 vs Univer Pro playground，2026-11-02，增量测试时先查此节避免重跑）

**SpreadJS 侧（全 ✅）**：批次 1 样式 29 项对象层全还原（min/max、logBase=10、orientation 反转、numFmt 0%、日期格式、刻度标签旋转 45°+字体颜色、tickMark、轴线样式、网格线颜色/虚线 dash/粗细、图例位置/字体、标签 showVal/showPercent/位置/千分位格式/单点文本、轴标题文本+旋转）。导入 21/21 存活、渲染即可见。已确认的降维：直方/排列→clusteredColumn、圆柱/圆锥/棱锥→3D 柱、分离型→普通型（见 make_baseline_charts 实测）。

**Univer Pro 侧（批次 1：29 项 = 19✅ + 3❌ + 7⚠仅模型层）**：
- ✅ 模型层还原：旋转（rotate=-45）、对数（scaleType log）、min/max、日期格式、标签字体颜色、轴线颜色粗细、网格线颜色粗细、图例位置字体、饼图百分比（pie.label.contentType 16 + format 0%）、单点标签（dataPoints[].label）、轴标题文本/颜色/旋转、标题隐藏（titles=null）、tick 位置/标签隐藏（tickLabelPosition）
- ❌ 确认不支持（三层全无）：网格线虚线 dash、次网格线 minor、图例项级删除
- ⚠ 仅模型层（值在但 Facade 不暴露）：主刻度单位 majorUnit
- 🖼 渲染：批次 1 样本 21/21 图表尺寸 0×0，Chrome 有头确认全部不可见（63 图样本时部分 4.5px 极扁可见——两种缺陷表现，不能互相外推）
- 亮点：内置 Edit chart UI 面板能力远超 Facade 文档（趋势线/刻度线/标签旋转/反转/对数/系列透明度全有控件）
- **SpreadJS 侧 UI**：设计器组件（在线表格编辑器）= 功能区+公式栏+侧面板+上下文菜单，可嵌入需单独部署许可；数据图表另有 DataChartConfigPanel。不可说"SJS 无 UI 面板"（已被用户指正）
